# InterestSeed 完整教程

这个教程只做一件事：

```text
把一条刷到的内容
变成 3 天内可验证的真实行动
```

不需要 API Key，不需要账号，不需要先把整个 Vault 整理好。

---

## 0. 安装

### 手动安装

1. 打开 [Releases](https://github.com/lxc248/-interestseed/releases)；
2. 下载最新：

```text
interestseed-v3.0.3.zip
```

3. 解压后得到：

```text
main.js
manifest.json
styles.css
```

4. 放进：

```text
<你的 Vault>/.obsidian/plugins/interestseed/
```

5. 重启 Obsidian；
6. 设置 → 第三方插件 → 关闭安全模式 → 启用 **InterestSeed**。

### 从源码构建

```bash
npm install
npm run build
```

把 `dist/` 里的：

```text
main.js
manifest.json
styles.css
```

复制到插件目录。

### 安装后先确认

```text
左侧栏出现 InterestSeed 图标
命令面板能搜索到 InterestSeed
```

如果看不到，检查：

- 插件目录是否是 `.obsidian/plugins/interestseed/`；
- `manifest.json` 是否是 UTF-8 无 BOM；
- 是否重启过 Obsidian。

## 1. 打开主视图

快捷键：

```text
Ctrl/Cmd + P
```

搜索：

```text
InterestSeed
```

执行：

```text
打开兴趣验证（图谱）
```

你会看到：

```text
左侧：兴趣验证视图
中间：宇宙星图
右侧：图谱洞察 / 节点详情
顶部：记录 / 收件箱 / 筛选 / 更多
```

---

## 2. 第一次冷启动

命令：

```text
冷启动问卷：从 0 长出第一张星图
```

做四个选择：

```text
现在的你，更接近哪种状态？
什么最容易让你忘记时间？
最近什么内容最容易让你停下来？
你希望这张图先长成什么？
```

然后：

1. 看草稿星图；
2. 逐项保留或删除种子；
3. 确认要写入的关系；
4. 点击写入。

冷启动默认给你：

```text
5 个种子
4–6 条候选连接
1 个意外连接
1 个 3 天兴趣试跑
```

### 不想做问卷

点击：

```text
先跳过，记录一条
```

会直接进入记录火花，而不是给你一张空白图。

---

## 3. 记录第一条内容

命令：

```text
记录一个兴趣火花
```

可以粘贴：

```text
抖音 / 小红书 / B 站 / YouTube 链接
一篇文章
一句让你停下来的话
```

然后点击：

```text
留下这个火花
```

它不会立刻替你写图谱，只会成为一个候选。

### 从当前笔记进入

打开一篇 Markdown 笔记，执行：

```text
把当前笔记加入分享收件箱
```

来源会标记为：

```text
Obsidian 笔记
```

点击来源标签可以回到原笔记。

---

## 4. 处理分享收件箱

命令：

```text
打开分享收件箱（列表 / 专注）
```

### 标准列表

默认是列表：

```text
来源
标题
摘要
留下并连接
只是路过
```

一次只看一条，不让收件箱变成收藏夹。

### 专注模式

点击：

```text
专注一条
```

键盘：

```text
←  只是路过
→  留下并连接
```

方向键只改变当前卡片，不会批量处理。

### 留下并连接

点击：

```text
留下并连接
```

在火花弹窗里：

1. 确认标题和主题；
2. 可选填“为什么留下”；
3. 可选选择连接到一个已有兴趣；
4. 点击：

```text
留下这个火花
```

### 只是路过

点击：

```text
只是路过
```

不会写入图谱。

这不是失败，而是一次有效判断。

---

## 5. 开始 3 天验证

命令：

```text
打开 3/7 天验证行动
```

第一次默认是 3 天。

每天只需要点一个：

```text
做了
只想过
没做
```

规则：

- 一个自然日只记录一次；
- 不伪造进度；
- 记录后可以撤销；
- 3 天结束后可以延长到 7 天。

### 为什么只有三个按钮

因为验证问题不是：

```text
今天学了什么？
```

而是：

```text
这个兴趣有没有进入真实生活？
```

---

## 6. 看时间线

选中一个节点。

右侧会出现：

```text
时间线
```

每条观察包含：

```text
更确定 / 变弱 / 有变化
日期
证据
来源
```

它回答：

```text
我为什么曾经在意？
中间发生了什么？
现在还成立吗？
```

---

## 7. 搜索上下文

点击顶部：

```text
筛选
```

搜索框支持：

```text
标题
标签
摘要
为什么留下
原始内容
来源路径
观察时间线
```

支持多词：

```text
观察 今天
```

两个词都存在才会命中。

搜索不会修改图谱。

## 8. 生成兴趣路线

打开：

```text
更多 → 导出 → 生成兴趣路线
```

或者命令：

```text
生成兴趣路线笔记（Markdown MOC）
```

输出：

```text
InterestSeed/兴趣路线 - {主题} - {日期}.md
```

包含：

```text
正在验证
验证中的线索
已连接的线索
等待判断
最近观察
下一步
```

只有你显式执行时才生成，不会自动覆盖笔记。

## 9. 视图模式

主视图有三种详情模式：

```text
graph         节点详情 / 图谱洞察
inbox         关系建议
discoveries   发现列表
```

规则：

- 进入关系建议或发现，会清空节点选择；
- 选择节点，会回到图谱详情；
- 搜索和筛选不会因模式切换被清空；
- 发现主题过滤只在发现模式内生效。

窄分栏下：

- 360px 以下变成图标优先；
- 300px 以下显示“拉宽分栏查看完整图谱”；
- 不把桌面布局硬压进极窄侧栏。

## 10. 连接 Agent（可选）

InterestSeed 不需要 Agent 也能完整使用。

需要时：

```bash
node mcp/server.mjs --graph "<vault>/.obsidian/plugins/interestseed/graphs/default.json"
```

MCP 是只读的：

```text
interestseed_get_graph
interestseed_next_step
interestseed_search_interest
interestseed_get_experiment
interestseed_get_context
```

资源：

```text
interestseed://graph
interestseed://experiment
interestseed://next
interestseed://context
```

不填 API Key，不填 Cookie。

## 11. 备份、撤销与隐私

### 备份

```text
更多 → 导出 → 导出 JSON
```

或命令：

```text
创建图谱备份
```

### 撤销

```text
更多 → 撤销
```

大部分图谱写入可以撤销。

### 隐私

```text
本地优先
不抓取平台
不存 Cookie
不自动写图谱
不自动生成路线
MCP 只读
```

## 12. 第一次 7 天怎么用

```text
第 1 天：只留一条内容，判断留下或路过
第 2 天：给留下的内容连一个已有兴趣
第 3 天：开始 3 天验证，点第一次
第 4 天：点第二次，不补写
第 5 天：点第三次，看时间线
第 6 天：生成兴趣路线，回看证据
第 7 天：决定继续、延长或放下
```

不要追求节点数。

追求：

```text
一次真实行动
一条真实证据
一个明确决定
```

## 常见问题

### 打开后没有图？

先执行：

```text
冷启动问卷：从 0 长出第一张星图
```

或者：

```text
记录一个兴趣火花
```

### 收件箱没有内容？

先执行：

```text
记录一个兴趣火花
```

或：

```text
把当前笔记加入分享收件箱
```

### 为什么不能自动抓取抖音？

InterestSeed 不保存 Cookie、不模拟登录、不抓取平台内容。

你粘贴链接或文字，系统只分析你主动提供的内容。

### 为什么路线没有自动更新？

路线是显式快照。

需要更新时重新执行：

```text
生成兴趣路线笔记（Markdown MOC）
```

### 插件在窄侧栏里很难看？

把分栏拉宽。

低于 300px 时，InterestSeed 会主动隐藏 NEXT 和实验条，只保留图标操作和画布。
