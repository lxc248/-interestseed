# 命令面板

InterestSeed 不把高频操作藏在设置里。所有核心动作都可以通过 Obsidian 命令面板完成。

打开：

```text
Ctrl/Cmd + P
```

搜索：

```text
InterestSeed
```

## 核心命令

| 命令 | 用途 |
| --- | --- |
| 打开兴趣图谱 | 回到主工作区 |
| 冷启动问卷：从 0 长出第一张星图 | 第一次建图 |
| 记录一个兴趣火花 | 粘贴分享或一句话 |
| 打开分享收件箱（列表 / 专注） | 一条一条判断 |
| 打开 3/7 天验证行动 | 看进度、开始记录 |
| 验证行动：今天做了 | 一键记录正向行动 |
| 验证行动：只想过 | 一键记录“想起但没有做” |
| 验证行动：今天没做 | 一键记录真实的没发生 |
| 导出分享星图（社交平台 PNG） | 生成社媒图片 |
| 打开兴趣总览（只读） | 看反馈和趋势 |
| 打开兴趣探索（只读/AI 可选） | 看主题、矩阵、节奏 |
| 创建图谱备份 | 在任何大改前备份 |
| 撤销 / 重做图谱操作 | 手动恢复 |

## 快捷键

InterestSeed 不抢占默认快捷键，避免和用户已有绑定冲突。

推荐手动绑定：

```text
设置 → 快捷键 → 搜索 InterestSeed
```

推荐绑定：

```text
记录一个兴趣火花      Ctrl/Cmd + Shift + S
打开分享收件箱        Ctrl/Cmd + Shift + I
验证行动：今天做了    Ctrl/Cmd + Shift + D
打开兴趣图谱          Ctrl/Cmd + Shift + G
```

## Focus Deck 键盘

当卡片获得焦点：

```text
←  只是路过
→  留下并连接
```

## 设计原则

- 命令面板优先，不要求记工具栏位置；
- 不设默认热键，避免与用户现有快捷键冲突；
- 所有命令都有明确的动作，不执行隐藏写入；
- 清空、修复等破坏性命令需要二次确认。
