## Short post

I save far more than I act on. So I built InterestSeed around one small loop:
capture → connect → 3-day experiment → evidence → next action.

It is local-first, uses a narrow AI request (ids, titles, tags and existing
edges only), and never writes to the graph without confirmation. It ships as a
CLI, local web dashboard, agent skill and read-only MCP.

Standalone 4.0.5 is out, with a deterministic build, SHA-256 and Sigstore
attestation:
https://lxc248.github.io/-interestseed/
