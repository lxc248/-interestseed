# InterestSeed 短视频传播方案

## 核心定位

> 你不需要先知道自己喜欢什么。做四个选择，长出第一张会生长的兴趣星图。

这不是“AI 知识库工具”，而是一次 **从 0 到 1 的兴趣启动体验**。

## 三个可拍的钩子

### 钩子 A：反常识

```text
“你不是没有兴趣。
你只是没有一个地方，把它们连起来。”
```

画面：空白输入框 → 四个选择卡 → 星图生长。

### 钩子 B：收藏夹困境

```text
“收藏了 100 个视频，
却没有一个兴趣真正长出来。”
```

画面：堆叠的收藏卡 → 一条线把它们连成图谱。

### 钩子 C：意外连接

```text
“AI 从我的四个选择里，
找到了一条我自己没看见的桥。”
```

画面：两条不相干的兴趣线突然连上。

## 40 秒主片结构

| 时间 | 画面 | 文案 |
| --- | --- | --- |
| 0–4s | 黑场、星尘、标题出现 | 你不需要先知道自己喜欢什么 |
| 4–9s | 收藏卡堆叠、问号 | 收藏夹越来越大，兴趣却没有形状 |
| 9–16s | 四张选择卡、进度条 | 四个选择，不需要写长文 |
| 16–23s | 种子节点与连线生长 | 你的兴趣，开始有形状了 |
| 23–29s | 草稿卡、置信度、意外连接 | AI 提案，不是替你决定 |
| 29–35s | 短视频卡飞入图谱 | 每一次停留，都可能是一条新连接 |
| 35–40s | Logo、星环、GitHub | 从 0 到一张会生长的兴趣星图 |

## 标题与封面

标题候选：

1. `我用 4 个选择，让 AI 长出了我的兴趣星图`
2. `收藏夹越大，兴趣越没有形状？`
3. `别再问自己对什么感兴趣了`
4. `给你的兴趣做一次 3 分钟起跑`
5. `AI 没有替我决定，它只是把桥指给我看`

封面：

- 左侧大字：`你不需要先知道自己喜欢什么`
- 右侧：发光的兴趣星图；
- 底部：`InterestSeed · 3 分钟兴趣起跑`

## 平台分发

### 抖音 / 视频号 / 小红书

- 15 秒版：只保留“四个选择 → 星图生长 → CTA”；
- 40 秒版：完整叙事；
- 60 秒版：加“火花捕获 + 7 天实验”。

### B 站 / YouTube

- 标题带 `Obsidian`、`AI`、`知识管理`、`兴趣图谱`；
- 视频简介放 GitHub 链接和“3 分钟起跑”；
- 置顶评论：安装方式和 demo Vault。

### GitHub

- README 首屏放视频封面；
- Release 附件包含 `interestseed-launch.mp4`；
- 用 `assets/interestseed-launch-cover.png` 作为社交预览图。

## 传播节奏

```text
Day 0   发布仓库 + 40 秒主片
Day 1   发“收藏夹困境”切片
Day 2   发“意外连接”切片
Day 3   发“7 天兴趣实验”挑战
Day 7   发第一批用户星图（征得同意）
Day 14  发“从 0 到 1”完整案例
```

不要用：

- 假排行榜；
- 未经同意公开用户图谱；
- 无限信息流；
- “AI 自动接管你的笔记”这种夸张承诺。

## 10k 收藏的衡量方式

收藏/star 不是靠一个功能，而是靠三个瞬间：

1. **3 秒**：标题让人停下来；
2. **10 秒**：星图生长让人想看结果；
3. **40 秒**：用户知道“我也能马上做一次”。

产品内对应：

```text
90 秒内完成 5 个种子
3 分钟内确认第一条关系
5 分钟内开始第一个 7 天实验
```
