# 开始建图：InterestSeed 的 0 → 1 机制

## 为什么需要它

空白画布会让新用户停在第一步。InterestSeed 不问“你对什么感兴趣”，而是给用户四个具体的、可以凭直觉回答的场景。

## 四个选择

| 轮次 | 问题 | 目的 |
| --- | --- | --- |
| 01 | 现在的你，更接近哪种状态？ | 确定起点：项目、探索、研究、起步 |
| 02 | 什么最容易让你忘记时间？ | 识别心流：创造、理解、表达、连接 |
| 03 | 最近什么内容最容易让你停下来？ | 捕获注意力磁场 |
| 04 | 你希望这张图先长成什么？ | 确定第一版结构：项目地图、探索路径、作品集、生活实验 |

## 从选择到星图

```text
4 个选择
  → 4 个种子
  → 1 个 7 天实验节点
  → 4–6 条带证据的候选边
  → 1 个意外连接
  → 1 个神秘方向（完成实验后解锁）
```

## 三条产品原则

1. **不写长文**：选择比描述更容易开始。
2. **先看见，再确认**：实时生长动画让用户马上获得反馈。
3. **不自动写回**：AI 和规则只提供草案，用户逐项确认，写入可撤销。

## 图谱对象

每个种子节点保留：

```json
{
  "type": "topic",
  "tags": ["兴趣起跑"],
  "metadata": {
    "seedSprint": true,
    "evidence": "来自你的选择：最近什么内容最容易让你停下来？",
    "confidence": 0.9
  }
}
```

每条边保留：

```json
{
  "origin": "ai",
  "status": "confirmed",
  "confidence": 0.81,
  "evidence": ["从你的兴趣磁场生成的可执行下一步"]
}
```

## 7 天兴趣实验（严格协议）

生成的 activity 节点保存一个完整实验状态：

```json
{
  "nextStep": true,
  "experimentStatus": "active",
  "experimentState": {
    "title": "7 天兴趣实验",
    "hypothesis": "我愿意用真实行动验证这个兴趣是否值得继续投入。",
    "metric": "每天记录一次兴趣强度、精力值和一个具体证据；连续 7 条才算完成。",
    "startedAt": "...",
    "status": "active",
    "logs": []
  }
}
```

规则：

- 一个自然日只能记录一次；
- 每条记录必须包含至少 4 个字的真实观察；
- 同时记录兴趣强度与精力值（1–5）；
- 不能通过点击按钮直接跳到第 7 天；
- 只有 7 条有效日志才会变成 `complete`；
- 完成后展示平均兴趣、平均精力与复盘提示；
- 元数据仍是图谱节点的一部分，可随 Vault 本地保存、导出和撤销。

主工作区只显示当前进度与“记录今天”；具体记录在实验工作台中完成。

## 火花捕获

```text
粘贴短视频链接 / 一句话
→ 生成 1 个候选种子
→ 可选连接到已有兴趣
→ 进入图谱；可确认、可编辑、可删除
```

只保存用户主动提供的文本或链接，不抓取视频内容，不需要读取整个 Vault。

## 缺口教练

图谱洞察会检测：

- 孤立节点；
- 桥接节点；
- 待确认关系；
- 主题覆盖。

用户点击“补一条连接”后，写下一个具体观察。系统创建一个观察节点，并生成一条 `suggested` 关系；用户仍需在图谱里确认。

## 测试

`tests/SeedSprint.test.ts` 覆盖：

- 4 个选择轮次；
- 确定性草案；
- 所有边端点有效；
- 1 个实验节点；
- 不完整选择不产生无效边。
