# 兴趣起跑：InterestSeed 的 0 → 1 机制

## 为什么需要它

空白画布会让新用户停在第一步。InterestSeed 不问“你对什么感兴趣”，而是给用户四个具体的、可以凭直觉回答的场景。

## 四个选择

| 轮次 | 问题 | 目的 |
| --- | --- | --- |
| 01 | 现在的你，更接近哪种状态？ | 确定起点：项目、探索、研究、起步 |
| 02 | 什么最容易让你忘记时间？ | 识别心流：创造、理解、表达、连接 |
| 03 | 最近什么内容最容易让你停下来？ | 捕获注意力磁场 |
| 04 | 你希望这张图先长成什么？ | 确定第一版结构：项目地图、探索路径、作品集、生活实验 |

## 从选择到星图

```text
4 个选择
  → 4 个种子
  → 1 个 7 天实验节点
  → 4–6 条带证据的候选边
  → 1 个意外连接
  → 1 个神秘方向（完成实验后解锁）
```

## 三条产品原则

1. **不写长文**：选择比描述更容易开始。
2. **先看见，再确认**：实时生长动画让用户马上获得反馈。
3. **不自动写回**：AI 和规则只提供草案，用户逐项确认，写入可撤销。

## 图谱对象

每个种子节点保留：

```json
{
  "type": "topic",
  "tags": ["兴趣起跑"],
  "metadata": {
    "seedSprint": true,
    "evidence": "来自你的选择：最近什么内容最容易让你停下来？",
    "confidence": 0.9
  }
}
```

每条边保留：

```json
{
  "origin": "ai",
  "status": "confirmed",
  "confidence": 0.81,
  "evidence": ["从你的兴趣磁场生成的可执行下一步"]
}
```

## 7 天兴趣实验

生成的 activity 节点带：

```json
{
  "nextStep": true,
  "experimentDay": 1,
  "experimentStatus": "active",
  "experimentStartedAt": "..."
}
```

主工作区显示 `DAY 1 / 7` 进度条，点击“完成今天”推进一天；第 7 天完成后节点保留，成为图谱里的真实反馈。

## 火花捕获

```text
粘贴短视频链接 / 一句话
→ 生成 1 个候选种子
→ 可选连接到已有兴趣
→ 进入图谱；可确认、可编辑、可删除
```

只保存用户主动提供的文本或链接，不抓取视频内容，不需要读取整个 Vault。

## 缺口教练

图谱洞察会检测：

- 孤立节点；
- 桥接节点；
- 待确认关系；
- 主题覆盖。

用户点击“补一条连接”后，写下一个具体观察。系统创建一个观察节点，并生成一条 `suggested` 关系；用户仍需在图谱里确认。

## 测试

`tests/SeedSprint.test.ts` 覆盖：

- 4 个选择轮次；
- 确定性草案；
- 所有边端点有效；
- 1 个实验节点；
- 不完整选择不产生无效边。
