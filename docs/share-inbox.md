# Share Inbox

Share Inbox 是 InterestSeed 的分享收件箱：刷到的内容先进入队列，用户再一次处理一条。

## 使用

1. 打开兴趣图谱；
2. 点击工具栏「收件箱」；
3. 粘贴分享文本；
4. 看到当前卡片：
   - 左滑 / `←`：只是路过；
   - 右滑 / `→`：留下并连接；
   - 也可以直接点按钮。

## Focus Deck

一次只显示一张卡：

```text
01 / 02
平台
标题
原始分享
主题
[只是路过] [留下并连接 →]
```

处理完自动轮到下一条。

## 行为

```text
同一 URL 在待处理状态下去重
一次只处理一条
只是路过不写入图谱
关闭 Obsidian 后队列仍然保留
移动端 interestseed-share URI 进入同一队列
```

## NEXT

存在待判断分享时，主视图顶部显示：

```text
NEXT · 3 条分享待判断
打开分享收件箱，一次处理一条
[打开收件箱]
```
