# Share Inbox

Share Inbox 是 InterestSeed 的分享收件箱：刷到的内容先进入队列，用户再一次处理一条。

## 使用

1. 打开兴趣图谱；
2. 点击工具栏「分享收件箱」；
3. 粘贴分享文本；
4. 选择「处理这一条」；
5. 在判断卡中选择「留下这个火花」或「只是路过」。

## 行为

```text
同一 URL 在待处理状态下去重
一次只处理一条
只是路过不写入图谱
关闭 Obsidian 后队列仍然保留
移动端 interestseed-share URI 进入同一队列
```
