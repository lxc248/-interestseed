# InterestSeed 定位

## 一句话

**别收藏更多，验证一个。**

InterestSeed 是给“收藏很多、但不知道哪个值得做”的人的兴趣验证器：

> 把一条刷到的内容，变成 3 天内可以验证的真实行动，用证据决定继续还是放下。

## 品类

不是：

```text
笔记工具
第二大脑
AI 图谱
收藏夹
聊天助手
```

而是：

```text
兴趣验证器 / Interest Validator
```

图谱是证据的载体，不是产品本身。

## 用户

```text
18–35 岁
经常刷短视频、收藏帖子、存课程
收藏很多，真正开始的很少
不想再被“更多内容”淹没
想知道：我到底是三分钟热度，还是真的愿意做？
```

## 核心问题

现有工具解决的是：

```text
怎么保存更多
怎么整理更好
怎么让 AI 记住更多
```

用户真正的问题是：

```text
哪一个值得我现在做？
做了之后，还喜欢吗？
```

## 产品承诺

```text
一条内容
→ 一个候选
→ 一次决定
→ 3 天真实行动
→ 一条证据
→ 留下 / 放下 / 继续
```

不是让用户拥有更多兴趣，而是让用户对少数兴趣有证据。

## 为什么独一无二

### 1. 从“收藏”转向“证伪”

大多数工具奖励保存。

InterestSeed 奖励：

```text
真实做过
有具体证据
3 天后仍然成立
```

它允许一个兴趣被放下，而且把“放下”当成有效结果。

### 2. 一次只做一个决定

不是无限信息流，不是批量整理。

```text
今天只判断一条
今天只做一个下一步
```

### 3. 时间化证据

每个节点有：

```text
captured / judged / connected / experimenting / reviewed
sourceRef
why
observations[]
```

它回答：

```text
我为什么曾经在意？
中间发生了什么？
现在还成立吗？
```

### 4. 本地优先的信任

```text
Obsidian 本地
不抓取平台
不存 Cookie
不自动写图谱
不自动生成路线
MCP 只读
```

在高星 Agent 和 memory 产品都在争夺“自动接管”的时候，InterestSeed 选择：

> 人保留决定权，AI 只提供候选。

### 5. 可演示的闭环

```text
分享 / 笔记
→ 收件箱
→ 留下并连接
→ 3 天试跑
→ 时间线
→ 兴趣路线
→ 下一步
```

这条链路可以在一分钟内演示，也可以在两轮真实 UI 测试中验证。

## 竞争位置

| 类型 | 代表 | 它们强在 | 它们不解决 |
| --- | --- | --- | --- |
| 图谱 / 第二大脑 | Obsidian 图谱、Smart Second Brain | 连接、检索、整理 | 哪个值得做、做完还喜不喜欢 |
| 收藏 / 稍后读 | Readwise、MyMind | 捕获和回忆 | 真实行动 |
| 习惯 / 任务 | Things、habit tracker | 执行 | 兴趣判断与证据 |
| AI memory | Mem0、Graphiti、Cognee | 记住、检索、时间化 | 人的决定与真实世界验证 |
| Agent 工作台 | Claude Code、Cursor | 把 Agent 放进 vault | 兴趣验证闭环 |
| 原生数据库 | Obsidian Bases | 表格 / 看板 | 判断、实验、证据 |

InterestSeed 占的是交叉点：

```text
上下文捕获
+ 人的判断
+ 真实行动
+ 证据时间线
+ 本地优先
```

## 本赛段策略

### 只证明一件事

> 一条内容，能不能在 3 天内变成一个有证据的真实行动？

不要用“节点数、关系数、AI 生成量”证明产品。

### 演示脚本

```text
0–10s  收藏很多，但不知道哪个值得做
10–20s 粘贴一条内容 → 收件箱 → 只判断这一条
20–35s 留下并连接 → 3 天试跑
35–55s 每天点一下：做了 / 只想过 / 没做
55–70s 时间线出现证据
70–85s 兴趣路线 → 下一步
85–90s 本地优先，不自动替你决定
```

### 评分指标

```text
决策完成率
3 天完成率
每条兴趣的证据数
3 天后回访率
放下率（不是失败，是有效结果）
```

不是：

```text
节点数
AI 生成字数
收藏数
```

### 赛段交付

```text
1. 90 秒演示：一条内容 → 3 天证据
2. README 第一屏：一句话定位
3. 两轮真实 UI 模拟：学生 + 上班族
4. 一个可验证的本地数据模型：taskState + observations
5. 一个只读 Agent 接口：MCP context
```

## 不要做

```text
AI 聊天侧栏
自动抓取平台
自动写图谱
自动生成路线
云端账号
积分系统
无限信息流
```

这些都会把产品拉回“另一个第二大脑”。

## 对外一句话

> InterestSeed 不帮你收藏更多，它帮你验证一个兴趣是否值得继续。

英文：

> **Stop collecting. Start proving.**
