# 视图模式

InterestSeed 的主视图只有三个详情模式：

```text
graph
inbox
discoveries
```

## 不变量

1. 同一时刻只有一个模式；
2. `inbox` 和 `discoveries` 不保留节点选择；
3. 从任一模式选择节点，会回到 `graph` 并显示节点详情；
4. 搜索和筛选在模式切换时保留；
5. 发现主题过滤只在 `discoveries` 内生效；
6. 执行“更多”里的动作后，菜单自动关闭。

## 模式说明

### graph

- 默认模式；
- canvas + 选中节点详情；
- 没有选中时显示图谱洞察。

### inbox

- 关系建议列表；
- 不修改节点选择；
- 通过“更多 → 待确认关系”进入；
- 进入时清空节点选择。

### discoveries

- 发现列表；
- 可按主题过滤；
- 通过“更多 → 发现”或总览主题进入；
- 进入时清空节点选择。

## 样式

`discoveries` 使用深色表面，不跟随宿主主题的浅色卡片，避免在深色星图上出现白块。

## 已知边界

- Share Inbox 是独立弹窗，不属于这三个详情模式；
- 视图模式不写入图谱数据；
- 视图模式不改变筛选条件。
