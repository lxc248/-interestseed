## 发现并修复

### BUG-04（高）Canvas 导出 ID 只有 16 种

```text
复现：5000 个节点 buildJsonCanvas
结果：唯一 ID 只有 16 个
根因：旧 hexId 每次只取 LCG 的低 4 位，低 4 位周期为 16
影响：大于 16 个节点的 Canvas 会大量 ID 冲突，边可能指向错误节点
修复：两路独立 FNV-1a 32 位哈希拼成 64 位 ID
回归：5000 节点唯一 ID = 5000，ID 长度 16
```

### BUG-03（中）收件箱重复 id

```text
复现：inbox.load 两条相同 id 的记录
结果：两条都保留，resolve 只命中第一条，第二条永远 pending
修复：load 时按 id 去重，保留第一条
回归：BugHuntInbox.test.ts
```

### BUG-02（中）BOM JSON 被当成损坏数据

```text
复现：图谱 / 发现 / MCP 读取带 UTF-8 BOM 的 JSON
结果：JSON.parse 失败，进入损坏恢复或 MCP 报错
修复：读取时剥离 \uFEFF
回归：BugHuntPersistence.test.ts + MCP smoke 4/4
```

### BUG-01（中）绝对路径被当成合法 vault 来源

```text
复现：isValidSourceUri('C:\\secret.md') / '/etc/passwd' / UNC
结果：true
影响：外部绝对路径被显示为内部来源
修复：拒绝 /、\、盘符路径
回归：BugHuntPaths.test.ts
```
