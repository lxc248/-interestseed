metric and the raw answer disagree. Always inspect the original answer; do not

## Why the result is limited

- InterestSeed has no public website or canonical domain; only a GitHub repo.
- The local model had no web search and no citations.
- A GEO audit measures model answers; a repo-only project gives the model very
  little to recognize.
- The `--domain github.com` scope is only a placeholder; it is not a real
  InterestSeed domain.
