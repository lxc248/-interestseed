# InterestSeed 2.7.9 性能优化（画布与渲染）

继续沿 performance 方向优化热路径。

## 1. Canvas 帧预算减半

文件：

```text
src/ui/CosmicGraphCanvas.ts
```

原实现：

```text
requestAnimationFrame 每帧都 draw()
```

新实现：

```text
动画时间仍按显示频率推进
draw() 每两帧执行一次
```

效果：

```text
Canvas 重绘成本减半
动画观感仍保持
```

## 2. refresh 复用同一份图

文件：

```text
src/ui/InterestSeedView.ts
```

原实现：

```text
refresh() 里 getGraph() 后，
renderNextStep() 再次 getGraph()
```

新实现：

```text
refresh() 把 graph 传给 renderNextStep(graph)
避免同一帧重复克隆图谱
```
