# InterestSeed 1.7.0 — Focus Deck

这一版借用了流行内容产品最有效的一种交互：

```text
一屏一卡
一个决定
滑走或留下
```

但不是把 InterestSeed 做成短视频，而是把“判断一条分享”做成 Focus Deck。

## 1. 一屏只处理一条

收件箱打开后只看到：

```text
当前这一条
01 / 02
平台
标题
原始分享
主题
```

不再先看到一列卡片。

## 2. 三种操作，零学习成本

```text
左滑 / ← ：只是路过
右滑 / → ：留下并连接
按钮：也可直接点
```

移动端可以滑动，桌面端可以拖拽或键盘。

## 3. 主按钮更明确

```text
只是路过        留下并连接 →
```

「留下并连接」是唯一金色主行动，不再是模糊的“处理这一条”。

## 4. 添加分享退到二级

处理当前卡片时，下面只有：

```text
再放一条进来
```

不打断当前判断。

## 5. 保留原有边界

- 一次只看一条；
- 队列剩余数量可见；
- 只是路过不写图谱；
- URL 去重；
- 关闭 Obsidian 后仍然保留；
- 不自动抓取平台内容。
