# InterestSeed 1.5.2 — 把“兴趣起跑”和“实验轨道”说清楚

这一版只改用户看到的语言，不改数据结构和核心功能。

## 改名

```text
兴趣起跑 → 开始建图
实验轨道 → 我的实验
```

## 为什么

### 开始建图

它解决的是第一次打开时的冷启动：

- 四个选择；
- 生成第一张草稿星图；
- 用户确认后才写入；
- 不是测试，也不是自动替你决定兴趣。

“开始建图”比“兴趣起跑”更像一个用户能立即理解的动作。

### 我的实验

它不是另一个页面，而是图谱里的行动节点分组：

- 3 天试跑；
- 延长到 7 天；
- 每天记录一次；
- 记录兴趣强度、精力、证据；
- 完成后复盘。

“我的实验”比“实验轨道”更像用户自己的东西。

## 兼容性

- 内部 tag `兴趣起跑` 保留，已有图谱不需要迁移；
- 只改显示标签、命令名、按钮和文档；
- 旧数据和旧图谱仍然可用。
