# InterestSeed 3.5.0 — AI 一次只给一条建议

## 不再有批量待确认

之前：

```text
5 张卡片
待确认 / 已接受 / 已撤销
一屏状态
```

现在：

```text
AI 建议 · 1 / 5
一张卡
连上 / 换一个 / 先不用
```

没有“待确认”列表，没有状态墙。

## 连上之后

```text
顶部：已连上这条关系
按钮：撤销 / 完成
下一条建议自动出现
```

撤销后：

```text
关系 33 → 32
提示：已撤销这次写入，图谱恢复原状
继续看下一条
```

## 关系名可改

```text
模型只给“相关”时，可以直接改成
“共享方法”“同一个实验”“跨项目连接”
```
