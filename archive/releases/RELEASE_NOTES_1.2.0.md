# InterestSeed 1.2.0 — 先做 3 天，再决定要不要 7 天

**从真实抖音的一次停留，走到一张包含美妆、运动、游戏的兴趣星图；再先试 3 天，由用户决定是否延长到 7 天。**

## 这一版新增

- **3 天兴趣试跑**：先做 3 天，完成后再决定是否延长到 7 天；
- **主题优先视图**：默认聚焦最大主题，顶部主题轨可切换「全部」与单个轨道；
- **移动分享入口**：`obsidian://interestseed-share?text=...` 与剪贴板入口；
- **真实生活兴趣词**：新增「美妆、穿搭、个人风格」与「游戏、虚拟世界、玩家文化」；
- **分享主题识别**：底妆、跑步、羽毛球、塞尔达、开放世界等生活词也能归类；
- **一次只处理一个火花**：留下并连接，或只是路过；
- **短标题图谱**：长标题不挤压行星；
- **修复预填分享按钮不可提交**：移动端/初始文本进入时立即启用主按钮。

## 设计边界

- 不抓取抖音/小红书私密收藏；
- 不调用平台私有接口；
- 没有真实字幕时，只分析用户主动分享的文本；
- 不伪造每日实验证据；
- 同日重复记录仍会被拒绝。
