# InterestSeed 1.8.0 — 熟悉优先，两个身份验证

这一版不是加更多功能，而是把“大家能接受的样子”做成默认。

## 1. 默认是标准列表

分享收件箱打开后先看到：

```text
2 待判断
[粘贴分享……] [放进来]

抖音 · 游戏：塞尔达为什么让我绕路
[留下并连接] [只是路过]
```

不需要先学滑卡。

想专注时再点：

```text
专注一条
```

进入一屏一卡模式，随时可以：

```text
返回列表
```

## 2. 冷启动可以跳过，但不再跳到空白

之前：

```text
跳过 → 空白图谱
```

现在：

```text
先跳过，记录一条 → 直接打开火花记录
```

用户不完成四问，也能马上留下一条真实内容。

## 3. 两个身份的真实 UI 任务测试

### 大三视觉设计学生

```text
冷启动打开
→ 跳过
→ 记录一条设计分享
→ 标准列表
→ 留下并连接
→ 只是路过
→ 打开验证行动
→ 点“做了”
→ 撤销
```

结果：

```text
pendingAfterPass: 0
beforeLogs: 0
afterLogs: 1
restoredLogs: 0
```

### 工作 2–3 年的产品/运营上班族

```text
两条工作分享
→ 标准列表
→ 专注一条
→ 左滑路过
→ 返回列表
→ 留下并连接
→ 验证行动
→ 点“只想过”
→ 撤销
```

结果：

```text
pendingAfterSwipe: 1
beforeLogs: 0
afterLogs: 1
restoredLogs: 0
```

完整记录：

```text
review/1.8.0-persona-tests.md
```

## 4. 与之前相比

| 项目 | 之前 | 1.8.0 |
| --- | --- | --- |
| 新实验 | 7 天 | 3 天，可延长 |
| 每日记录 | 3 个字段 | 1 次点击 |
| 冷启动跳过 | 空白图 | 直接记录 |
| 收件箱默认 | 卡片 | 标准列表 |
| 高级交互 | 默认暴露 | 按需进入 |
| 命令入口 | 工具栏 | 工具栏 + 命令面板 |

## 5. 保留的边界

- 不自动写图谱；
- 不自动抓取平台；
- 不伪造实验记录；
- 测试结束后状态恢复；
- 一次只处理一条；
- 所有状态可撤销。
