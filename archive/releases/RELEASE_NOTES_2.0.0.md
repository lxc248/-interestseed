# InterestSeed 2.0.0 — 全量验收版

这一版不是增加一个功能，而是把 1.5–1.8 的所有改动收口成可发布的 2.0.0。

## 核心体验

```text
冷启动问卷
→ 记录一个火花 / 分享
→ 标准收件箱列表
→ 可选专注模式
→ 3 天试跑
→ 每天点一下
→ 回到图谱
```

## 2.0.0 包含

### 入口

- 工具栏只保留：`记录`、`收件箱`、`更多`；
- 高级操作进入「更多」；
- 所有核心动作进入 Obsidian 命令面板；
- 不抢占默认快捷键。

### 冷启动

- 四个选择；
- 可以跳过；
- 跳过后直接进入记录，而不是空白图谱；
- 默认生成 3 天试跑，而不是 7 天。

### 收件箱

- 默认是标准列表；
- 一眼看到待判断项；
- 「专注一条」进入 Focus Deck；
- 专注模式支持左滑 / 右滑 / 方向键；
- 随时返回列表；
- 只是路过不写图谱。

### 验证行动

- 每天三个一键选项：`做了 / 只想过 / 没做`；
- 详细观察可选；
- 一天只能记录一次；
- 不伪造证据；
- 撤销可恢复。

### 视觉

- 深色宇宙主视图；
- 总览、探索、分享、实验、收件箱统一深色；
- 详情面板按钮改为深色玻璃按钮；
- 最小可读字号与对比度提升；
- 主题优先星图。

### 数据与信任

- 本地优先；
- 不抓取抖音/小红书；
- 不存 Cookie；
- 不自动写入；
- 图谱备份、导出、撤销；
- 只读 MCP。
