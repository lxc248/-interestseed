## 本轮发现并修复

### 1. 右侧洞察标题被「Hero 标题」样式污染

`DetailPanel` 和 Explore Studio 曾共用 `.interestseed-insight-title`。Hero 的 `clamp(27px, 4vw, 42px)` 和渐变文字作用到右侧小卡片，导致标题被压成一字一行。

修复：拆分 `.interestseed-detail-insight-title`，保留 Explore Studio 的 Hero 标题样式。

### 2. 图谱初始缩放不可读

从旧画布保存的极小 zoom 会让 12 个节点缩成一小团。现在：

- 小型图谱的持久化 zoom 低于 `0.55` 时自动重新适应；
- 首次获得有效画布尺寸时自动 fit；
- 保留用户手动缩放能力。

### 3. 节点标签重叠

重写标签绘制：

- 选中 / hover / 邻居标签优先；
- 测量文本并做矩形碰撞检测；
- 碰撞时隐藏低优先级标签；
- 增加半透明标签底，提升明暗主题可读性。

### 4. 启动卡裁切

启动卡固定高度和单行描述导致 Agent/探索描述被截断。现在：

- 最小高度 66px；
- 描述最多两行；
- 窄侧栏下自动隐藏描述，只保留标题和图标。

### 5. 右侧面板宽度与溢出

- 详情面板宽度 352px、最小 300px；
- `.interestseed-detail-content` 独立滚动；
- 洞察卡强制 `width: 100%; min-width: 0`，避免 flex 子项被压扁。

### 6. Agent 视觉密度

- 头部高度与状态胶囊统一；
- 空态最大宽度 520px，标题 20px；
- 建议卡从满宽细条改为有层次的卡片；
- 输入区最大宽度 880px，圆角和阴影与主工作区统一；
- 增加窄容器下的换行与安全宽度。

### 7. Qwen 与 DSH 的边界

- Qwen 是默认 AI 后端，直接连接 DashScope / OpenAI-compatible；
- Base URL、模型和 Token 均由用户配置；
- Token 只进入 Obsidian SecretStorage，不进入 data.json；
- DSH 保留为可选 Agent，不再是千问必需依赖。

## Agent 单入口

产品已收敛为单一入口：**连接用户自己的 Agent**。

- DSH ACP / 用户自己的 Agent 命令；
- 用户自己配置命令、profile、模型；
- 支持流式消息、工具卡、权限卡、停止、新会话；
- InterestSeed 不保存 Agent 的模型凭据；
- 不再提供千问/DSH 双模式，也不在设置页展示免费模型平台。
