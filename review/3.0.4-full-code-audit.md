**发现并修复 1 个问题：**

```text
KEYDOWN-01
文件：src/ui/CosmicGraphCanvas.ts
问题：destroy() 移除了 pointer / wheel / click 监听，但漏了 keydown
修复：destroy() 增加 removeEventListener('keydown', this.handleKeyDown)
影响：视图销毁后键盘监听残留，可能重复触发选择
```
