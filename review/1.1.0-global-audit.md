# InterestSeed 1.1.0 — Global audit

## Scope

- Obsidian lifecycle and view lifecycle;
- graph mutation, persistence, undo and error paths;
- share intake → decision → graph → next action;
- experiment state, daily gate and completion;
- cosmic canvas performance, reduced motion and cleanup;
- student and office-worker journeys through real Obsidian CDP;
- release metadata, plugin loading, permissions and workflow.

## References studied

- `obsidianmd/obsidian-sample-plugin`: view/settings lifecycle, command registration and manifest conventions.
- `community-archive/obsidian-kanban`: stateful view structure and editor integration.
- `blacksmithgu/obsidian-dataview`: data import/query separation and large-graph thinking.
- `zsviczian/obsidian-excalidraw-plugin`: canvas performance, view state and keyboard/reduced-motion concerns.

The goal was not to copy their UI. The lesson was: keep the plugin lifecycle boring, keep the domain state explicit, and keep a single obvious action in the interface.

## Audit findings and fixes

### P0 — plugin could fail to load

`manifest.json` was rewritten with a UTF-8 BOM during the 1.1.0 metadata update. Obsidian did not discover the plugin.

Fixed by writing BOM-free UTF-8 JSON and verifying the first byte is `{`.

### P1 — two competing experiment actions

The NEXT bar and experiment strip both offered “record today”.

Fixed: the experiment strip owns that action; NEXT hides for the experiment-only state.

### P1 — generated experiment was counted as an orphan

The experiment node is an action, not an unclassified content node.

Fixed:

- excluded `metadata.nextStep` from graph orphan stats;
- excluded it from insight orphan cards;
- excluded it from NEXT’s “connect this node” branch.

### P1 — long graph labels made the map hard to scan

Fixed: graph labels use a compact title (colon/comma aware, 18 chars max). Full titles stay in the detail panel and raw metadata.

### P1 — spark decision was implicit

A spark could sit in the graph without a clear “keep or pass” moment.

Fixed: spark detail now shows:

```text
这个火花还只是一个候选。
它和你的哪个兴趣有关？
[留下并连接] [只是路过]
```

“只是路过” requires confirmation and removes the spark.

### P1 — share intake lacked user context

Fixed: the Spark modal now has an optional “为什么留下？” field, persisted as `metadata.why` and shown in the decision card.

### P2 — visual surfaces were inconsistent

Fixed:

- dark onboarding, spark and experiment modals;
- dark toolbar controls;
- experiment modal auto height;
- reduced-motion support in the cosmic canvas;
- event listener cleanup on canvas destroy.

### P2 — platform intake was opaque

Added deterministic parsing for:

- Douyin / Xiaohongshu / Bilibili / YouTube / web / plain text;
- title cleanup of common share noise;
- topic inference;
- explicit next question.

No private cookies, scraping, or fabricated transcripts.
