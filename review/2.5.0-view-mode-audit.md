# 2.5.0 全局逻辑与视图模式审计

## 发现

### 1. 两个布尔值可以同时为 true

旧状态：

```text
inboxOpen
discoveryOpen
```

问题：

- 进入发现时只关闭 inbox；
- 进入 inbox 时只关闭 discovery；
- 选择节点时只关闭 inbox，不关闭 discovery；
- 发现面板打开后，节点详情仍被隐藏。

结果：

```text
用户点击节点，但右侧仍然是发现列表。
```

### 2. 发现在打开时重置主题过滤

旧逻辑：

```ts
if (!this.discoveryOpen) this.discoveryThemeFilter = null;
```

从总览点击某个主题进入发现时，`discoveryThemeFilter` 先被设置，随后 `toggleDiscoveries` 又清空。

结果：

```text
主题过滤进入后消失。
```

### 3. “更多”菜单动作不关闭

`createQuickAction` 直接绑定 `onClick`，没有关闭父级 `<details>`。

结果：

```text
点击“待确认关系”后，菜单继续盖住详情面板。
```

### 4. 发现卡片跟随浅色宿主主题

发现面板使用 `--is-v2-surface`，在浅色 Obsidian 主题下变成白色卡片；

但主画布始终是深色星图。

结果：

```text
深色画布 + 白色卡片 + 低对比文字。
```

## 修复

### 单一模式

```ts
type DetailViewMode = 'graph' | 'inbox' | 'discoveries';
```

所有进入/退出都通过 `setMode`：

- `inbox` / `discoveries` 进入时清空选择；
- 选择节点时回到 `graph`；
- 单一状态同步按钮和面板可见性。

### 主题过滤

- 打开发现保留主题；
- 关闭发现清空主题。

### 菜单

`createQuickAction` 执行后关闭最近的 `<details>`。

### 深色发现

发现卡片、标题、描述、元数据、按钮统一为深色表面。
