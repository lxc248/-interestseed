# InterestSeed 3.0.5 动态安全审计

## 1. 外链协议与 opener 隔离

实际运行脚本：`promo/dynamic-security-audit.mjs`

步骤：

```text
1. 向收件箱写入一条 https 来源
2. 劫持 window.open 记录参数
3. 点击来源链接
```

结果：

```text
url: https://www.xiaohongshu.com/explore/dynsec-audit
target: _blank
features: noopener,noreferrer
```

结论：外链不会拿到 `window.opener`，且只对 http/https 走 `window.open`；其它字符串走 vault `openLinkText`。
