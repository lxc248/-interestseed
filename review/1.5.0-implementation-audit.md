# InterestSeed 1.5.0 — 实现审计与验证

- 工具栏从 12 个可见入口减到 `记录 / 收件箱 / 更多`；
- 高级操作移入“更多”；
- 火花弹窗移除四步说明，只保留“留下 / 只是路过”；
- 目标兴趣与“为什么”收进可选折叠区；
- 支持 `Ctrl/Cmd + Enter` 直接留下；
- 收件箱一次只展示一个候选；
- 处理完自动显示下一条。

## 本轮范围

按审批执行的四个方向：

1. Share Inbox + Theme-first
2. Social Share Studio
3. 只读 MCP
4. Trust / 大图

## 1. Share Inbox

实际执行：

```text
加入 2 条分享
→ 收件箱显示 2 条
→ 处理第一条
→ 点“只是路过”
→ 待判断从 2 变成 1
→ 图谱节点数不变
```

截图：

```text
review/sim-artifacts/14-share-inbox.png
review/sim-artifacts/15-inbox-process.png
review/sim-artifacts/16-inbox-after-pass.png
```

行为：

- 同 URL 待处理去重；
- 持久化到插件 data；
- 单条处理；
- “只是路过”不写图谱；
- NEXT 显示待判断数量；
- 移动端 URI 进入同一队列。

## 4. 只读 MCP

实际协议验证通过：

```text
initialize
tools/list
interestseed_get_graph
interestseed_next_step
interestseed_get_experiment
```

调用示例输出：

```json
{
  "serverInfo": { "name": "interestseed", "version": "1.5.0" },
  "toolCount": 4
}
```

文件：

```text
mcp/server.mjs
mcp/README.md
```

边界：

- 只读；
- 不访问网络；
- 不读取 Vault 其他笔记；
- 不暴露 sourceUri；
- 不抓取抖音/小红书。

## 5. Trust / 大图

- 收件箱上限 200 条；
- 分享图最多标注关键节点；
- 可隐藏不想公开的节点；
- 分享弹窗小屏可滚动；
- 后台隐藏时暂停 Canvas；
- `ShareInbox` 序列化与去重测试；
- `ShareCard` 预设与文案测试。

## 已知边界

- MCP 读取的是图谱文件快照，不监听实时修改；
- Share Inbox 是本地队列，不自动抓取平台；
- 分享卡片只使用当前图谱数据；
- Theme-first 当前是主题轨 + 默认聚焦，不是独立主题详情页。
