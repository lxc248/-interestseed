从 GitHub 搜索结果页（`performance` 按 stars 排序）中选取了与 TypeScript / Node 服务直接相关的高星项目，学习并实践两项可验证优化。

## 实践 1：搜索字段索引缓存

文件：

```text
src/ui/FilterBar.ts
```

原实现：

- 每次过滤，每个节点都重新拼接 `title + summary + why + raw + sourceRef + path + tags + observations`；
- 输入搜索时连续触发，产生重复字符串分配。

新实现：

- 为每个节点预计算 `NodeSearchIndex { path, searchable }`；
- 以 `graph.updatedAt + node.id` 为键缓存；
- 缓存上限 2048，超出清空重建；
- `filterGraph` 一次建索引，后续匹配复用。

效果：

```text
搜索输入从 O(n × 字段拼接) 变为 O(n × includes)
字符串分配次数显著下降
```

## 实践 2：MCP 图谱读取缓存

文件：

```text
mcp/server.mjs
```

原实现：

- 每次 `tools/call` 都 `readFileSync + JSON.parse` 整个图谱文件；
- 一个 Agent 会话内同一文件被反复解析。

新实现：

- 记录 `statSync(graphPath).mtimeMs`；
- mtime 不变时直接返回内存中的解析结果；
- 文件变化后自动失效并重新读取。

效果：

```text
同一 mtime 内，多次工具调用只读盘、解析一次
```
