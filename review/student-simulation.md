# 大学生第一次使用 InterestSeed：一次完整体验模拟

> 实际执行记录：2026-10-29，Obsidian 1.14.5 + 桌面抖音公开推荐流 + Obsidian CDP 自动化。
> 结果：14 个节点、11 条可见关系、Day 1 已记录、同日再次记录被拒绝。
> 证据截图：`review/sim-artifacts/`（01–10）。

> 角色：大三学生，非技术背景，每天刷抖音，收藏很多但从不回看。
> 场景：Windows 桌面，抖音桌面端公开推荐流。
> 目标：从“看到项目”到“得到一张自己的兴趣星图”。

> 测试说明：onboarding、火花弹窗、图谱写入和 7 天实验均走真实 Obsidian UI；为了不重复操作 7 次，额外的 6 条火花通过同一个 `captureInterestSpark` 公共入口写入，随后用 UI 检查图谱。

## 0. 我为什么点进来

我在 GitHub / 朋友分享里看到一张宇宙星图：中心一颗星核，外围是行星轨道，关系线是金色。

第一反应不是“这是知识管理工具”，而是：

> “这看起来像我的精神自画像，我想看看我的兴趣长什么样。”

这是产品最强的入口。

## 1. 我打开项目后的真实心理

README 第一句是：

> 你不需要先知道自己喜欢什么。

这句话对大学生很有效。因为大部分知识库产品都默认：

- 你已经知道自己要研究什么；
- 你已经有整理习惯；
- 你愿意先建文件夹。

但它没有。它先让我做四个选择：

```text
你更像哪种状态？
你想让兴趣先流向哪里？
什么最容易让你停下来？
你希望这张图先长成什么？
```

这四个问题不像设置，而像一次很短的性格测试。  
如果 2 分钟内能看到第一张图，我会继续。

## 2. 第一次 Star Sprint

我选了：

```text
状态：正在做一个东西
流向：刷到就先留下
磁场：AI、工具、效率
形状：项目地图
```

系统生成：

```text
5 个兴趣种子
4–6 条候选连接
1 条意外连接
1 个神秘方向
1 个 7 天实验
```

## 3. 打开抖音后的真实采集

我打开抖音桌面端，刷了几条：

- 一条关于 **Vibe coding / 用 AI 做产品**；
- 一条 **DeepSeekHarness 手搓粒子**；
- 一条 **Kimi 一周 AI 大事**；
- 一条 **Agent 技术圈**；
- 一条视觉很特别的 **“颠倒”** 视频；
- 一条 **中央选调生**；
- 一条 **“后排听不见将军”** 的职场沟通内容；
- 一条 **收到退款** 的生活消费内容。

这时我的真实状态不是“我要整理知识”，而是：

```text
这个挺酷，先存一下
这个跟我实习有关
这个好像和我正在做的项目有关
这个只是好笑，不一定要进星图
```

所以采集时最重要的不是“全部导入”，而是：

```text
这条内容为什么值得留下？
它和已有哪个兴趣有关？
它是短暂好奇，还是持续吸引？
```

如果每个链接都要我手动写理由，我会放弃。  
如果 AI 先给理由，我只需要点“留下 / 跳过”，我会继续。

## 5. 7 天实验

系统没有让我“点一下完成今天”，而是要求：

- 每天记录一次；
- 兴趣强度 1–5；
- 精力 1–5；
- 至少一句真实观察；
- 连续 7 条才完成。

我第一天的记录会是：

```text
今天用 AI 剪了一个 30 秒视频。
真正让我兴奋的不是工具，而是看到别人停下来看完。
兴趣 4 / 精力 3
```

这比“今天学习了 AI”真实得多。

但作为大学生，7 天有点长。  
如果第 2 天没有提醒，我很可能忘。  
所以实验需要一个**轻提醒**，或者先给一个“3 天试跑”。

## 6. 真实卡点

### 卡点 1：抖音到 Obsidian 的摩擦

我需要：

```text
复制链接 → 切到 Obsidian → 打开插件 → 打开火花 → 粘贴 → 等分析 → 确认
```

对于刷视频场景，这太长了。

**最重要改进：**

```text
抖音分享 → InterestSeed Inbox → Agent 自动提炼 → 我只确认
```

桌面端至少要有剪贴板监听或全局快捷键。

### 卡点 2：一次出现太多节点

第一次看到 18 个节点，我会不知道怎么读。  
我应该先看到：

```text
5 个主题
14 个行星
3 条最重要关系
1 个待确认
```

点开一个主题，再展开行星。  
`neural-creator-dashboard` 的**三层聚焦**正好解决这个问题。

### 卡点 3：我不知道“确认”后会发生什么

候选关系需要明确告诉我：

```text
确认后会写进图谱
可以撤销
不会自动覆盖我的笔记
```

否则我不敢点。

### 卡点 4：收藏不等于兴趣

我收藏“收到退款”可能只是觉得好笑，不代表我想研究消费。  
产品要允许我说：

```text
这个只是路过，不进星图
```

并且记住这个反馈。

### 卡点 5：没有 Obsidian 的同学

如果我没有 Obsidian，安装插件这一步就会流失。  
Agent Skill + 单文件 `star-map.html` 是必要的第二入口，但它不能取代主体验，只能是“先看到图”。

## 7. 我作为用户最愿意分享的瞬间

不是完成 onboarding，也不是 7 天实验完成。

而是第一次看到：

```text
“AI 工具” 和 “创作表达” 之间
出现一条我没想到的金色连接
```

那一刻我会截图发朋友：

> “你看，我刷了半年短视频，原来我一直在找的是这个。”

这就是 InterestSeed 的传播点。

## 8. 结论

### 会继续用吗？

会，但前提是：

1. 第一次星图在 3 分钟内出现；
2. 抖音链接进入成本低于 5 秒；
3. 我不需要一次确认 18 个节点；
4. 7 天实验有提醒，不是靠自律；
5. 我可以随时说“这条只是路过”。

### 产品最强的部分

```text
不是知识管理
不是 AI 摘要
是“我的兴趣第一次有了形状”
```

### 产品最危险的部分

```text
把“刷短视频”当成“学习”
把“收藏”当成“兴趣”
把“导入”当成“理解”
```

### 一句话

> 这个产品不应该让我整理更多内容，  
> 而应该让我第一次看见：  
> **我反复回到的几件事，正在形成一张星图。**
