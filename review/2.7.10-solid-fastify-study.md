# InterestSeed 2.7.10 学习报告

学习对象来自 GitHub `performance` 高星项目，而不是自行臆造优化。

## 学习对象

### solidjs/solid

核心原则：

```text
Fine-grained reactivity.
When a piece of state changes, only the code that depends on it will rerun.
```

### fastify/fastify

核心原则：

```text
An efficient server implies lower infrastructure cost.
Least overhead without sacrificing validations and developer experience.
```

## 对照 InterestSeed 后落地的实践

### 1. GraphStore.stats 派生状态缓存

文件：

```text
src/core/GraphStore.ts
```

之前：

```text
每次 stats() 都扫描全部 nodes 和 edges
```

现在：

```text
stats() 以 `${updatedAt}:${revision}` 为键缓存
只有图谱发生 mutation 时才重算
```

这与 Solid 的 derived state 一致：

```text
依赖没变，派生值不重算
```

### 2. MCP 读图缓存

文件：

```text
mcp/server.mjs
```

这与 Fastify 的“避免每次请求重复工作”一致：

```text
mtime 不变，不重复 readFileSync + JSON.parse
```
