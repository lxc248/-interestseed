# 2.6.2 全局 Bug 回归

> 测试环境：真实 Obsidian 桌面端，浅色 / 深色宿主、1280 宽桌面、480 宽窄栏。  
> 这是实际运行验证，不是只看 CSS。

## 1. 发现的问题

### P0：桌面宽度下搜索无法打开

旧规则：

```css
@container (min-width: 641px) {
  .interestseed-quick-action.is-filter-toggle { display: none; }
}
```

同时：

```css
.interestseed-root.has-graph:not(.is-filter-open) .interestseed-filter-host { display: none; }
```

结果：

```text
桌面宽度：筛选按钮隐藏 + 筛选面板隐藏
→ 用户无法搜索
```

这是全局功能 bug，不是样式小问题。

### P1：浅色宿主下实验弹窗低对比

实验弹窗背景：

```text
rgb(11, 15, 25)
```

但根文本颜色继承宿主浅色主题：

```text
rgb(34, 34, 34)
```

结果：

```text
深色背景 + 深色文字
```

标题和白底按钮之外的文字可读性不足。

### P1：浅色主题下筛选输入框变白

筛选面板背景是深色，但输入框继承浅色主题：

```text
背景 rgb(255, 255, 255)
```

和深色面板冲突。

### 已确认没有回归

- 窄于 300px 的侧栏：图标优先、提示拉宽、无横向溢出；
- 关系建议 / 发现 / 节点详情模式切换；
- 从发现或关系建议选择节点回到详情；
- 更多菜单执行动作后关闭；
- 来源链接回到原笔记；
- 分享收件箱模态框；
- 概览 / 探索深色表面。

## 2. 修复

### 搜索入口

- 641px 以上重新显示筛选按钮；
- `is-filter-open` 时桌面也显示筛选面板；
- 筛选输入框使用深色表面和浅色文字。

### 实验弹窗

- `.interestseed-experiment` 和 `.interestseed-experiment-modal .modal-content` 设置深色表面文本 fallback；
- 标题、卡路里说明、按钮保持浅色。
