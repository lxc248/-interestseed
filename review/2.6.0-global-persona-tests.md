## 3. 全貌结论

### 1.8.0

优点：

- 最快；
- 核心判断闭环已经成立。

缺点：

- 没有“为什么留下”的证据；
- 没有来源回跳；
- 没有可读路线；
- 视图状态没有统一。

### 2.3.1

优点：

- 时间线和路线成立；
- 来源可追溯；
- 实验闭环完整。

缺点：

- 搜索还不能覆盖来源/观察；
- 视图模式仍有布尔值冲突；
- 发现卡片在深色画布上出现白色表面。

### 2.6.0

优点：

- 1.8 的快速主流程保留；
- 2.3 的时间线、来源、路线保留；
- 上下文搜索可用；
- 单一视图模式；
- 定位从“兴趣图谱”升级为“兴趣验证器”。

结论：

> **2.6.0 是当前最完整的产品形态，不是最快的版本。**

## 4. 取哪个

```text
如果只比速度：1.8.0
如果只比证据：2.3.1
如果比完整产品：2.6.0
```

最终选择：

```text
2.6.0
```

理由：

1. 两轮都完成，错误为 0；
2. 冷启动、来源、时间线、验证、路线、搜索、视图模式全部走通；
3. 没有为了新功能增加主界面入口；
4. 路线仍然显式生成，不自动写；
5. 定位与产品行为一致。

## 5. 这轮发现的可优化点

### 搜索命中数

学生查询 `theme-b-two` 返回 `2/19`，因为节点和来源路径都命中同一份上下文。

不是错误，但下一轮可以：

```text
同一标题 + 同一 sourceRef 的节点合并为一个结果
```

### 回访用户路径

回访用户不需要冷启动，直接进入收件箱和专注模式；这是正确的。

不需要为回访用户增加新的欢迎页。

### 视图模式

关系建议 / 发现 / 节点详情切换已经稳定。

继续保持：

```text
一个模式
一个选中状态
一个详情出口
```
