- use `InterestSeed` as the name of a fork or competing product;

- present a modified version as the official InterestSeed distribution;
- remove or obscure copyright, NOTICE or attribution notices.

## Allowed

- Refer to InterestSeed by name when describing the original project;
- State that your project is “based on InterestSeed” with a link to this repository;
- Use the code under AGPL-3.0, including for study, modification and
  redistribution under the same license.

## Required for forks

A public fork should:

1. use a different product name and icon;
2. preserve the LICENSE, NOTICE and copyright notices;
3. clearly disclose modifications;
4. link back to the original repository;
5. avoid implying that the fork is endorsed by InterestSeed.

For commercial licensing, brand permission or partnership, contact the
maintainer through the repository issue tracker first.
