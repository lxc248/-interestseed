Security & privacy

Local by default.
Verifiable by design.

InterestSeed reads a vault you already own. It does not need an account, a hosted database or a cloud sync service. This page states the actual boundaries, including the limits.

What stays local

  • Notes, source paths and the graph stay in your Markdown vault.
  • The standalone dashboard binds to 127.0.0.1, not a public interface.
  • The API key lives in the environment or .interestseed/key, not in the browser.
  • No telemetry and no automatic graph writes.

The AI boundary

The relation request sends only node ids, titles, tags and existing edge pairs. It does not send note bodies, source paths or the whole vault. You must explicitly grant AI consent before a request is made.

Server protections

  • State-changing routes accept JSON only.
  • Cross-origin and cross-site browser requests are rejected.
  • Static paths are resolved inside the web root; encoded traversal is tested.
  • Request bodies are capped at 1 MiB; oversized bodies return 413.
  • API responses use no-store, nosniff, no-referrer and same-origin resource policy.
  • Static pages use CSP, X-Frame-Options: DENY and no-referrer.

The local server deliberately trusts the local machine. Any process that can talk to loopback is inside the trust boundary. It is not a multi-tenant service and should not be exposed to a network.

MCP is read-only

The MCP server exposes the graph, the next step and experiment state. It does not write. --minimal limits the surface to the next step and the current experiment.

Release integrity

  • 4.0.8 is built by the release-standalone workflow.
  • The published zip has a SHA-256 digest on the download page.
  • GitHub build provenance is generated with Sigstore.
  • npm run check:release verifies the digest, attestation subject, workflow ref and Sigstore signature.
  • CI runs CodeQL, npm audit and the full unit, E2E and accessibility gates.

Reporting a problem

Use the repository's private security advisory flow: Report a vulnerability. Do not post secrets or private vault content in a public issue.

Limits

  • There is no independent human security audit yet.
  • The local server is not designed to be exposed beyond loopback.
  • MCP full mode exposes more graph metadata than --minimal.
