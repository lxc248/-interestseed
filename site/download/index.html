What is in 4.0.8

  • Route failures return a stable generic 500; internal exception text stays on stderr.
  • MCP --minimal exposes only the next step and current experiment.
  • MCP graph path errors are stable tool errors, not filesystem details.
  • Static file headers and encoded path boundaries are covered by regression tests.
  • 540 Vitest + 11 MCP smoke tests passing.

Which surface do I use?

SurfaceUse it when
CLIYou want scripts, or you do not use Obsidian.
Local webYou want the graph, one AI suggestion and the experiment strip.
Agent skillYou want an agent to follow the one-suggestion contract.
MCPYou want read-only graph context in an MCP client.

Requirements

  • Node.js 22 or newer.
  • A folder of Markdown files.
  • Optional: an OpenAI-compatible local endpoint for AI suggestions.
