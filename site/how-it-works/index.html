How it works

One testable connection.
Three days of evidence.

InterestSeed is a local-first interest validator for any Markdown vault. It does not help you save more. It helps you find out whether a saved interest deserves your time.

The loop

01Capture
02Connect
03Experiment
04Review

Capture a note, a project, or a saved idea. Your local AI suggests one defensible connection. You connect it, skip it, or change the relation. Then you run a 3-day experiment and log one real observation per day.

What the AI actually sees

The AI boundary is intentionally narrow. The request contains only:

  • node ids
  • short titles
  • tags
  • existing edge id pairs, to avoid duplicate suggestions
It does not send note bodies, source paths, full vault contents, cookies, or platform data. The model returns one suggestion, not a batch of pending cards.

A 3-day experiment is not a productivity score

A connection is a hypothesis. The experiment is a small reality check:

  1. Day 1: do one small action and write what actually happened.
  2. Day 2: repeat, or notice that you avoided it.
  3. Day 3: write the evidence, then choose continue / change / drop.

The output is a decision you can defend, not a score you can optimize.

Install

unzip interestseed-standalone-v4.0.9.zip
node interestseed-standalone-v4.0.9/cli.js init --vault "<vault>"
node interestseed-standalone-v4.0.9/cli.js serve --vault "<vault>" --port 4173

Open http://127.0.0.1:4173. No account, no cloud sync, no automatic graph writes.

FAQ

What is InterestSeed?

InterestSeed is a local-first interest validator for any Markdown vault. Local AI suggests one testable connection, then a 3-day experiment decides whether to continue or drop it.

Is InterestSeed an Obsidian plugin?

Obsidian is optional. The standalone runtime includes a CLI, a local web dashboard, an agent skill and a read-only MCP server. The Obsidian plugin is a compatibility surface.

Does InterestSeed send my notes to a cloud model?

The Explore AI request sends only node ids, titles, tags and existing edge pairs. It never sends note bodies, source paths or vault contents.

What is a 3-day experiment?

A 3-day experiment is a small test after you connect two notes. You log one real observation per day; evidence decides whether to continue, change the direction, or drop the interest.

Is InterestSeed open source?

Yes. The code is AGPL-3.0-only. The name, logo and visual identity are covered by a separate trademark policy. Commercial closed-source or hosted use needs a commercial license.
